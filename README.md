# Credit Card Fraud Detection Using Machine Learning

# Project Overview
This project uses Machine Learning to identify potentially fraudulent credit card transactions.

# Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- Logistic Regression

# Project Workflow
1. Load and explore the credit card transaction dataset.
2. Examine legitimate and fraudulent transactions.
3. Balance the dataset using undersampling.
4. Split the data into training and testing sets.
5. Train a Logistic Regression model.
6. Evaluate the model's performance.

# Dataset
The project uses a credit card transaction dataset. The dataset file is not included in this repository and must be obtained separately.

# How to Run
1. Install the required Python libraries.
2. Download the dataset and place `creditcard.csv` in the location expected by the notebook.
3. Open `creditcard_fraud_detection.ipynb` in Jupyter Notebook.
4. Run the cells in order.

# Objective
To explore how machine learning can help identify fraudulent credit card transactions.
